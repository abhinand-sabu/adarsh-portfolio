# Project Requirements: Creative Portfolio Web App

## Roles & Headlines
- **Dual Focus:** Graphic Designer & Video Editor prominently displayed on the landing page.

## Navigation & Sections
- Split-category entry on main page:
  - **Video Editing**
  - **Poster Designing**
- Dedicated view/page for each category.

## Dynamic Content & Upload Features
- **File Upload Capability:** Direct upload feature in both category sections to showcase media (videos/thumbnails for editing, high-res posters/images for graphic design).
- **Profile / Avatar:** Easily swappable profile picture and bio.

## Theme & Aesthetic
- **Vibe:** Premium, sleek, cinematic.
- **Palette:** 
  - Dark Red & Deep Blue base tones
  - Gold & Silver metallic accents

## Hosting & Architecture
- Static/JAMstack deployment ready for Netlify.
- Headless CMS / BaaS integration for zero-cost maintenance.
